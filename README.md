# ad-report-media

広告ナレッジベース（スプレッドシート）に表示する画像の置き場です。
[ad_report](https://github.com/az304845-sudo/ad_report) のボットが自動で更新します。**人は編集しません。**

- `images/kb-lp-*.jpg` … 配信中・配信済みLPのスクリーンショット（自動取得）
- `images/kb-cr-*.jpg` … Metaで実際に配信した広告クリエイティブ

スプレッドシートの `=IMAGE()` は公開URLしか表示できないため、このリポジトリは公開しています。
載せるのは**すでに広告として世に出ているもの**だけで、未出稿の素材や社内資料は置きません。
